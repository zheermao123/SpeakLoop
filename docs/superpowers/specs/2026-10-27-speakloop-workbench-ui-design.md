# SpeakLoop UI 设计 Spec v3.0 — "Workbench" 桌面工作台

- 日期：2026-10-27
- 状态：待用户审阅
- 关系：**全站替代**主规格书 `2026-10-01-speakloop-design.md` §8 + §8.1（iOS HIG v1.6）；主规格书应在实施计划获批时同步升版 v1.7 并指向本文件
- 视觉世代记录：Claymorphism（≤v1.5）→ iOS HIG（v1.6）→ **Workbench（v3.0，本文件）**

## 1. 背景与动机

用户提供一套 AI 助手型桌面 SaaS 仪表盘参考图（侧栏导航 + 问候 Hero + 琥珀渐变 AI 简报卡 + 富文本活动流 + 彩色徽章 + 待办清单），裁定**全面推翻**现有 iOS HIG：顶栏横向导航是移动范式妥协，与 Electron 桌面形态不匹配；参考图的工作台范式与 SpeakLoop 首页数据（本周练习/生词进度/错误分布）天然对应。

用户已选定方案 A（六页全部换新，iOS HIG 完全退役）；练习页**布局保留**（双栏 + iMessage 气泡形状），仅换 token。

## 3. 壳与导航

- `Nav.tsx` 重写为**左侧栏 232px**（桌面/浏览器同构，不做人肉双壳）：
  - 顶部：logo 色块 + 「SpeakLoop」
  - 导航项（Phosphor 图标 + 文字）：仪表盘 `/`、场景 `/scenarios`、生词本 `/vocab`、设置 `/settings`；生词本角标 = 非 mastered/ignored 计数
  - 激活态：`rgba(0,0,0,.05)` 圆角 10 填充；hover `.03`
  - 底部常驻：语音状态胶囊（`VoiceBanner` 紧凑形态：绿就绪/琥珀加载/红离线）
- `ExeTitlebar` 不动（拖拽区/窗口按钮），侧栏避开其高度；Mica 继续生效，网页端回退 `#F5F5F7`
- 内容区 max-width 1200px、padding 32px、独立滚动

## 4. 页面规格

### 4.1 `/` 仪表盘（对标参考图三件套）

1. **问候 Hero**：按时段「早上好/下午好/晚上好」+ 👋（装饰性文本 emoji，不属结构图标，不受 Phosphor 规则约束）
2. **AI 简报卡**（`--brand-grad` 全宽 + `--shadow-hero`）：📅 日期头（参考图「January 17,2026」式）+ 富文本「本周你完成了 `N 次对话`，还有 `K 个生词`待复习。」数字下划线加粗、分别链到练习记录与生词本；底部 💡 Insights 行：Top3 错误类型提示轮播（‹ › 切换 + 圆点指示）
3. **左栏（2fr）练习动态**：会话按 今天/昨天/更早 分组（组头灰字 + hairline）；行 = 场景色块图标（复用现有四场景色）+ 富文本「你完成了 **{场景}**，得分 **{分}**，**{n} 处**可改进。」（无 report 时「你练习了 **{场景}**，用时 {x} 分钟」）+ 右侧相对时间
4. **右栏（1fr）**：待复习生词卡（≤5：单词 + 音标 + 状态胶囊 + 发音键）+ 场景磁贴 2×2（彩色 12% 底圆角方块 + 图标 + 场景名 → `/practice/[id]`）
5. 现有三张统计卡（本周练习/生词进度/错误分布）**吸收进**简报卡与 Insights，不再独立成卡

### 4.2 `/scenarios`

行卡列表：彩色图标方块 + 场景名 + 一句描述 + 难度胶囊 + 右侧「开始」；自定义场景表单区仅换肤，交互零改动。

### 4.3 `/practice/[id]`（布局红线页）

- 双栏 310px/自适应、玻璃 dock、goals 进度条、气泡形状（18px + 6px 尾角）**全部保留**
- 换肤：AI 气泡白底 + `rgba(0,0,0,.06)` 描边；用户气泡 `#5B5BD6` 白字；教练气泡琥珀 `#FFF8E1` + `#FFE082` 边；dock 毛玻璃 `rgba(255,255,255,.85)`+blur20 不变
- **不回退红线**：录音键 `#FF3B30` 静态（F1，无脉冲）；悬停翻译 JS 瞬时 `zhShown`（F3，禁纯 CSS hover）；TTS 进度/队列/挂死守卫组件仅换肤（T1-T3）

### 4.4 `/report/[id]`

分数 Hero（40px 大数字 + 总评）+ 亮点 + 逐句纠错行（原声回放 + 改进对照，类型胶囊：语法=红 / 用词=橙 / 地道表达=靛蓝）+ 生词候选采纳/忽略；结构不动，全量换 token。

### 4.5 `/vocab`

To Do 式清单：按状态分组（组头「未学 5」式计数徽章）；行 = 掌握勾选框（选中绿色 ✓）+ 单词（粗）+ 音标（灰）+ 释义 + 状态胶囊 + 发音键 + 删除；语义与 API 零改动。

### 4.6 `/settings`

白卡分组行替代 inset-grouped；输入框白底 + `rgba(0,0,0,.08)` 边 + 12px 圆角；开关保留 iOS 绿 `#34C759`；Key 尾 4 位回显、三区测试连接等语义零改动。

## 5. 全局红线（历史验收结论，一律不回退）

| 红线 | 来源 |
|---|---|
| 录音键红色静态、无无限脉冲 | F1 |
| 悬停翻译 JS 瞬时显示，禁 `:hover` 纯 CSS | F3 |
| TTS 队列防死 + 进度 + 挂死守卫 | T1-T3 |
| 心跳 2s / 兜底 75s / 多标签保活 | 自动停止竞态修复 |
| 生产零 Mock，假件仅存 `tests/fixtures` | Mock 移除 |
| Electron：Mica / 无边框 / 权限放行 / `will-navigate` 白名单 | 桌面端交付 |
| Phosphor 矢量图标做结构图标（emoji 仅限问候语装饰） | A1 时代规则延续 |

## 6. 测试契约

- 基线 133 tests 必须保持绿；若重命名测试断言的类名（如 `vocab-status-pill`），须同一提交内同步更新测试并在计划中显式列出
- 优先保留语义类名，只改其样式定义，降低测试面扰动

## 7. 验收标准

1. `npm test` / `npm run typecheck` / `npm run build` 全绿
2. `scripts/console-check.mjs` 四页 200、零控制台错误
3. 六页无 iOS 蓝顶栏残留；颜色/圆角/阴影均来自新 token——组件与页面**不得引用 `--ios-*` 变量或 iOS 旧色值**（`#007AFF` 仅允许存在于 globals.css 的 `--tint` 定义及状态胶囊"未学"色）
4. Electron 冒烟：侧栏布局 + 标题栏拖拽 + Mica 透出正常

## 8. Non-Goals

- 暗色模式
- ⌘K Quick Search 命令面板（参考图元素，YAGNI 裁定不做）
- 多工作区切换器、通知铃铛、日历视图
- 练习页布局/交互重构（仅换肤）

## 9. 实施期修订备案（设计侧裁定）

1. **四场景磁贴色重映射**：§4.1 原文"复用现有四场景色"（含 iOS 旧值 `#007AFF/#5856D6/#30B0C7/#FF9500`）与 §7.3 颜色红线冲突，重映射为 interview `#5B5BD6`、standup `#FFB300`、oneonone `#34C759`、smalltalk `#FF7847`。
2. **无分数文案**：§4.1 动态流句式原文含"得分 N"，但 `Report` 数据结构无分数字段——正式句式改为纠错数/轮次驱动（"有 N 处可改进 / 表达干净无改进点 / N 轮对话"）。
3. **生词本状态标签**：§4.5 组头标签落地为 未学/认识中/已掌握/已忽略；原状态 `<select>` 由勾选框（mastered ↔ learning 快速切换）+ 只读胶囊替代，`PATCH` 通道保留，四态精调下拉列为 fast-follow。
